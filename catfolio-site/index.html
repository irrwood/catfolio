双指区间测量

长按并加入第二指，移动端点查看区间涨跌。

细节与数据说明
  • 长按曲线，保持第一指，再加入第二指
  • 移动两个端点，查看起止日期与区间变化
  • 组合曲线与收益对比支持区间查看

截图为原生区间选中状态，使用演示数据；不同图表的金额与收益口径不同。

立体持仓热力图

用面积与颜色查看持仓分布，展开后按收益或行业查看。

细节与数据说明
  • 轻点展开，查看持仓占比与涨跌
  • 切换今日 / 持有期，或按板块分组
  • 开启 ETF 穿透，点按直接持仓查看详情

截图为演示持仓的收起状态；在 App 内点按可展开。

收益来源 · 胜利复盘

拆分主要盈利持仓的历史贡献，复盘收益来源。

细节与数据说明
  • 本金、主要盈利持仓、其他收益分层展示
  • 长按查看某一天，切换时间范围
  • 点按图例隐藏或显示，重新聚焦收益来源

按当前股数回推历史市值，不包含已卖出持仓；截图为演示组合，不是完整历史交易归因。

市场轮动 · RRG

用 RRG 比较六个市场指数相对标普 500 的强弱与动量。

细节与数据说明
  • StockCharts 来源的 RS-Ratio 与 RS-Momentum
  • 30 周轨迹、指数选择与历史回放
  • 来源时间、刷新状态与离线快照

StockCharts 周线快照；最新周点可能尚未收盘，数据日期见界面。

板块轮动

查看 11 个美国行业板块的相对位置、周度轨迹与历史回放。

细节与数据说明
  • 领先、减弱、落后、改善四象限
  • 板块选择、周轨迹与历史回放
  • 板块最近收盘表现与走势详情

采用板块相对强弱与动量方法，不是 JdK RRG。更新延迟时沿用最近可用快照，数据日期可在 App 内查看。

策略编曲家

写下投资想法，检查筛选规则、执行步骤与模拟结果。

细节与数据说明
  • 写策略、策略步骤、结果三个工作区
  • 自然语言草稿，经 AI 整理后检查候选规则
  • 指标、筛选、排序、模拟预算与风险保护

截图为新版草稿入口。当前以可识别的美元美股日线为主，只读分析与模拟，不自动下单，也不是历史回测。

内部人士交易

查看公开申报中的内部人士买卖，区分主动交易与计划交易。

细节与数据说明
  • 主动买卖 / 全部交易切换
  • 汇总买卖金额，查看人员和交易明细
  • 过滤识别出的计划交易、代扣税及行权卖出

来源为 Nasdaq / SEC Form 4。过滤依赖披露标签及规则识别，可能不完整。

收入构成

按业务或地区拆分收入，并比较历年占比。

细节与数据说明
  • 产品与业务 / 地区两个维度
  • 流向图展示收入规模与构成占比
  • 按年度切换，比较业务结构

截图为 ORCL 2025 财年业务构成，来自 FMP 本地年度快照；与最新三表报告期可能不同。

分析师历史回顾

将历史目标价、评级与同期股价对照。

细节与数据说明
  • 股价与历史目标价对照
  • 查看不同月份的推荐建议
  • 月度快照和来源日期清晰可见
  • 查看一致评级与目标价

使用本地月度快照，覆盖依公司而定；目标价代表分析师观点，不是收益承诺。

单指查看单日

沿曲线拖动，查看某一天的日期与数值。

细节与数据说明
  • 长按后单指拖动，逐日查看
  • 日期、数值与曲线指示线同步变化
  • 配合时间范围切换，查看长短周期

截图为原生单日选中状态，使用演示组合。

账户管理

通过 SnapTrade 个人 API 或其他支持的方式添加账户，统一查看持仓、市值与收益。

细节与数据说明
  • 使用自备 SnapTrade 个人 API 凭证只读连接券商账户
  • 添加支持的券商与账户，不限制连接数量
  • 全部账户统一查看持仓、收益与资产分布
  • 按需切换指定账户，独立查看与对比

截图为演示账户。SnapTrade 连接需自备个人 API 凭证并完成只读授权；可连接的券商与数据范围取决于 SnapTrade 和对应券商。

组合首页

汇总资产、净入金与持仓收益，查看历史曲线和个股变化。

细节与数据说明
  • 市值、净入金、持仓盈亏与历史曲线
  • 单日查看、双指区间测量
  • 持仓排序、今日与持有期口径、热力图

新版原生界面，使用完全虚构的演示组合。

今日收益与组合透视

查看今日盈亏，按行业和持仓拆分贡献，给组合做一次 X-Ray。

细节与数据说明
  • 今日盈亏、市场基准与持仓涨跌贡献
  • 按行业拆分，可展开查看持仓（Portfolio X-Ray）

截图为演示组合的今日详情。按当前持仓与最近报价推算，未计入今日买卖影响；用于辅助判断，不是买卖信号。

ETF 穿透

穿透受支持 ETF 的底层持仓，识别与直接持股的重叠。

细节与数据说明
  • 展开支持基金的底层股票
  • 合并直接持仓与 ETF 间接暴露
  • 识别重叠持仓，按暴露大小排序

截图为穿透后的热力图。覆盖取决于基金快照，部分使用指数代理。

收益分析

用 TWR、MWR 或现金流镜像，与市场基准比较收益。

细节与数据说明
  • 现金流镜像、TWR 与 MWR 收益口径
  • 基准对比、时间范围与区间测量
  • 回撤曲线、最大回撤、估值成长矩阵

演示组合的 TWR 对比界面；可切换 MWR 和现金流镜像，数据口径随选择变化。

个股详情

在价格曲线上查看买卖标记、成本线、持仓盈亏与汇率影响。

细节与数据说明
  • 历史价格、买卖标记与成本参考线
  • 跨账户持仓、盈亏及汇率盈亏计算
  • 52 周区间、Volume Profile 与 POC / VAH / VAL
  • 查看可用的公司相关 Polymarket 事件

演示持仓的买卖标记与成本线；报价、历史曲线和持仓快照可能来自不同时间。

成交量与 52 周位置

细节与数据说明
  • Volume Profile 与成交峰值 POC
  • VAH / VAL 价值区间及成本参考

截图为个股页成交量区块；成交分布、52 周数据与报价可能有不同的更新时点。

期权 OI

细节与数据说明
  • 7、30、90 天到期范围

ORCL 期权链快照。限支持的美国美元股票 / ETF；OI 不代表成交量或必然支撑阻力。

货币自动换算
