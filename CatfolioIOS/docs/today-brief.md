# 今日总结

页面分三层，均复用已有行情和研究服务：

1. **即时摘要**：从 `TodayDetailView` 已算好的贡献值生成整体变动、已报价持仓的涨跌数量、主要正负贡献和行业贡献。没有网络也能显示；报价刷新时立即更新，不重新算收益率或让 AI 计算金额。
2. **简短 AI 解读**：同时检索最多三只重点股票，兼顾正负贡献。只补充有来源的公司动态，保留事件日期与行情日期的区别。生成期间保留完整即时摘要，失败不留下未完成的新闻断言。
3. **详细文章**：点击股票、行业或基准打开独立文章。复用短解读来源并读取原文，解释关键事件、数字和业务影响。简短解读完成后最多预备两篇重点股票文章，其他主题按需生成。

公开检索只传公司名称、代码和交易日期，不传账户金额。行情百分比可能含汇率影响，不能当成交易所原币报价去解释新闻因果。AI 不重复页面已显示的金额与涨跌幅。

`TodayBriefStore` 缓存短解读和主题文章；`TodayBriefEvidenceCache` 合并同一公开标的的并发检索及原文读取。缓存有效期为 15 分钟，显示生成时间；交易日、语言、持仓集合或行业成员改变会使用新的页面缓存。刷新行情不会反复触发 AI。

无实质证据时不生成“暂无公开催化”“未找到关联证据”等正文。短解读为空时保留程序化内容，详情页保留相应行情和更新入口。实际服务失败提供重试入口。页面只展示带 HTTP(S) 来源的 AI 内容。

生成规则要求交叉检查事件日期、报告期和财报发布日期，省略互相矛盾的时间推论。详细文章发布前额外进行一次编辑复核，检查日期、比率、预测归属和来源内的矛盾；复核失败不发布未复核草稿。引用编号统一显示为 `[1]`，与可点击的股票标记分开处理。

另有确定性的同单位数量比较校验：例如“600 万部不到 1,000 万部的一半”会整句省略。此检查覆盖中文“一半”关系，不代表对所有新闻事实的自动验证。

## Perplexity API 调研（2026-10-20）

官方已有 [Agent API](https://docs.perplexity.ai/docs/agent-api/quickstart) 和其中的 [Finance Search](https://docs.perplexity.ai/docs/agent-api/tools/finance-search)。Agent API 可组合 `web_search`、`finance_search` 与原文读取能力；金融工具覆盖行情、财报、分析师预期、公司事件等，具体标的覆盖情况依数据源而定。

所查公开文档中没有发现直接返回 Finance Watchlist 页面成品摘要的接口。可以使用公开研究接口生成相似内容，但不应依赖网页内部接口。本版继续使用应用已配置的 `LocalAIClient`、OpenRouter 搜索和原有公开原文抓取流程，没有新增 Perplexity 凭证或切换 AI 服务商。
