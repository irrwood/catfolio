# iOS 个股页排版复核

复核了 320pt 和 393pt 宽度、中英文、浅色与深色、普通字号和辅助功能大字号下的个股页。范围包括页首报价与成交读数、持仓数据、价格走势图与账户选择、成交量分布、52 周区间、期权持仓墙，以及内部人士交易、分析师预期和盈利历史卡片。

确认并修复的问题：

- 长名称、多个交易币种和同日买卖会挤压页首报价；成交读数改为按宽度换行，并只根据实际交易记录预留高度，拖动价格图时下方图表不再上下跳动。持仓数据的长标题与金额在窄屏改为上下排列。
- 成交峰值、现价和成本相近时，三个价格标签原本互相覆盖。现在标签错开，并用细线指回原价位；52 周区间的高低价在空间不足时分两行，保留完整金额。英文成交量说明中的句子间距也已修正。
- 320pt 屏幕上的期权 ZOOM 控件原本显示为省略号，辅助功能大字号时只剩 `ZO...`。空间不足时现在将到期范围和 ZOOM 分两排。
- 内部人士交易摘要的两列固定金额曾挤占交易名称；分析师评级、四个目标价、来源时间和盈利历史图例/季度标签也已改为随宽度与字号调整。
