06实现分叉

两条数字字体入口行为不同

Typography.number(scale) 调用 text(...) 再加等宽数字；number(size:) 经过 NumericAlternates。相同数字角色的字符特性路径不同。

建议 让 scale 与 size 两个入口复用同一数字字体构造；是否有肉眼差异仍需原生字形验证。

07可读性风险

注释灰在浅色底上偏淡

SettingsTemplate.footnote = #B6B6B6；浅色页底 #EEEFEF。下方提供实际颜色与计算对比度，低对比度会让小字号注释更难读。

建议 保留色样用于比对；优先调整承载说明、来源和状态的文字灰度。
