# 策略回测 Tab 计划（Strategy Lab）

更新时间：2026-06-12
新增一个独立 tab，用于**自由 Python 策略回测**，结果像 AI 聊天页那样按"一次运行=一条记录"保存、可回看。

## 已确定的产品决策
- **策略编写**：用户自由写 Python 代码（最灵活）。
- **标的范围**：任意股票代码（需按需拉取并缓存任意 ticker 的日线历史）。
- **会话形态**：一次运行 = 一条历史记录（参数+结果快照），左侧列表可点回看。运行记录式，非多轮对话。
- **执行环境**：面向本地 macOS 桌面 App——跑在用户自己机器上，本地执行可接受。（多用户 web 版需真沙箱，见"安全"一节，是上 web 前的硬门槛。）

---

## 架构总览

新路由 `/strategy`（标签"策略回测"），独立于现有 `/backtest`。四个部分：

```
┌─ 策略编辑器 (Python) ─┬─ 配置表单 ─┐     运行 → 后台子进程执行 → 结果
│  代码 / 模板          │ 标的/区间   │            │
│                      │ 资金/调仓/费 │            ▼
├──────────────────────┴────────────┤     SQLite 持久化（每次运行一条）
│  结果区：净值曲线 + 指标 + 回撤 + 交易明细       │
└────────────────────────────────────┘
左侧：运行历史列表（像聊天记录，点开载入参数+结果）
```

### 1. 策略编写（自由 Python）
- 前端：代码编辑器（CodeMirror，轻量、可内联打包）。
- 约定一个**策略契约**，用户实现一个函数，例如：
  ```python
  def strategy(ctx):
      # ctx.history: 各标的日线 DataFrame（已对齐日期）
      # ctx.date: 当前调仓日；ctx.indicators.sma(...) 等内置指标
      # 返回目标权重 dict，如 {"AAPL": 0.5, "SPY": 0.5}
      ...
      return weights
  ```
- 提供**文档化的 API 表面**（数据访问 + 常用指标 SMA/EMA/RSI/动量/波动率），让用户不依赖外部库也能写出大多数策略。预置 numpy / pandas。

### 2. 执行引擎
- 后端 `POST /api/strategy/run`：收 `{code, universe, start, end, capital, rebalance, fees}`。
- **在子进程中执行**用户代码：超时限制（如 30s）、崩溃隔离、捕获 stdout/异常回传前端。
- **回测内核**：自建轻量向量化引擎（基于 pandas），与现有手写风格一致、依赖少。按调仓频率（日/周/月）调用 `strategy()` 拿目标权重，计算净值、交易、扣费。
  - 备选：引入 `vectorbt`/`bt` 库（功能强但重）。**建议先自建薄引擎**，需要再换。

### 3. 数据层（任意标的）
- 复用现有 Yahoo chart 拉取 + `get_history` 的思路，扩展成**任意 ticker 历史服务**：`get_history_for(tickers, start, end)`，按标的缓存日线 JSON（TTL，如 12h）。
- 首次回测某标的时按需拉取并落缓存；后续命中缓存。

### 4. 运行持久化（一次运行=一条记录）
- 用 **SQLite**（`sqlite3` 标准库，零新依赖，单文件 `strategy_runs.db`）——天然适合"列表+回看"，也为将来 DB 迁移埋种子。
- 每条运行记录字段：`id, created_at, name, code, config(json), metrics(json: CAGR/Sharpe/MaxDD/Vol/总收益/胜率), equity_curve(json), trades(json), warnings`。
- 数据写入用户数据目录（`~/Library/Application Support/Helm/`，与桌面 App 计划一致）。

### 5. UI（运行记录式，借鉴 AI 聊天页布局）
- **左侧栏**：运行历史列表，每条显示名称 + 关键指标（如 CAGR）+ 日期；点击载入该次的代码+参数+结果。顶部"新建回测"。
- **主区**：
  - 上：代码编辑器 + 配置表单（标的、起止日期、初始资金、调仓频率、费率）+「运行回测」。
  - 下：**净值曲线**（组合 vs 基准，ECharts）、**指标卡片**、**回撤曲线**、**交易明细表**。
- 运行是异步的：点运行→后台子进程→前端轮询状态（复用现有 spinner/轮询模式）→完成后渲染并自动存为一条记录。
- 复用 v4 卡片/图表主题，并**应用本次的暗色图表修复**，让新图表从一开始就不刺眼。

## 安全（重要）
- **本地桌面**：子进程 + 超时 + 限制 `import`（禁网络/文件系统危险调用）即可，因为跑在用户自己机器、用户自己的代码。
- **多用户 web 版**：自由执行 Python 是高危。上 web 前必须换成真沙箱（RestrictedPython / 容器 / gVisor / 独立执行服务）。**这是 web 多租户化的前置门槛**，记在 `docs/multi-tenant-roadmap.md` 关联项。
