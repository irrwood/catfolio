# StockCharts RRG 原生对照页

新增独立 iOS 页面「市场轮动 · RRG」，入口在收益表现的「行情与 AI」区及研究页。现有板块轮动 v2 页面、数据、算法与 Web 页面保持不变。

来源为用户提供的 https://stockcharts.com/freecharts/rrg/?tailLength=30 。公开页面默认内容为 `$INDU $COMPQ $NYA $XAX $TSX $CDNX`，基准 `$SPX`，周线，一年历史。读取时页面会重置 URL 的尾迹参数；原生按用户要求固定 30 周尾迹，即当前点加之前 30 个周点，共 31 个观察值。回放每步仍为完整 30 周窗口，不包含所选结束日期之后的观察。

直接保存来源 `jdkratio`、`jdkmom`、各指数价格及 `$SPX` 价格。没有反推或仿写 JdK 公式，也没有套用板块 v2 的 MAD、tanh 或标签迟滞。横纵轴线性映射，以 100 为中心；UIKit 贝塞尔曲线经过原始每个周点，无箭头。原生卡片显示来源指标和价格，百分比为当前 30 周首尾价格比值减一，与动量指标分开。

首次可离线查看打包的来源快照：响应时间 `2026-09-10 12:59:54 America/New_York`，捕获时间 `2026-09-10T16:59:56Z`，共 53 周。应用进入页面或手动刷新时用临时 WebKit 会话正常加载公开来源网页，读取该网页自己收到的 RRG 响应；不保存 Cookie 或认证令牌、不使用私人 API、不改写来源网站。可见图表、回放和列表均为原生界面。保留来源链接与时间，提示最新周点可能尚未收盘。

数据必须包含正确的基准、周期及完整六标的；日期、有限正值、完整性与顺序经过校验。请求超过 30 秒、加载失败、格式不符或返回更旧数据时保留先前快照。页面退出时终止加载并移除 WebKit 消息监听。来源网页响应格式可能变化，届时会显示更新失败并保留已有数据；没有将非公开数据接口作为生产稳定 API 承诺。
