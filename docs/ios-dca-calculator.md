# iOS 定投策略对比

入口：研究 → 工具 → 定投计算器。原生 SwiftUI，资金图使用个股页、收益页共用的 `StandardLineChart`。布局参考 Figma `EtNSXmasS8lz9JzrWUoMd9` 的 `385:4085`，并按后续用户要求调整。

## 当前界面

1. 顶部直接显示回测资金图：自定义策略、固定定投、自定义策略累计投入。统一淡色刻度、网格、端点与长按读数；图例横向并排，仅显示线型和名称（自定义策略、固定定投、累计投入），较大字号下可横向滚动，点图例可单独查看，再点恢复全部。
2. 图表左上标的选择保留 SPY、QQQ、VTI、AAPL、MSFT、NVDA、TSLA、TSM 预设；搜索复用离线证券目录，支持代码、英文名称和已收录的中文简称，限制为当前引擎支持的美元美股／ETF，点选后加载对应行情。未收录的标的不虚构搜索结果。
3. 定投金额（滑杆 sheet，仅基础金额）、每周／每月。另有「策略条件」入口：自然语言 → AI 整理 → 规则预览／参数调整 → 应用到回测。只在已应用规则存在时显示摘要。
4. 起始／结束日期各用一个原生 compact DatePicker，并排显示，点击直接打开日期选择器，无中间日期配置 Sheet；选择立即更新，非法区间就地提示并禁用回测。修改后保留旧结果并标明待重算。
5. 仅有已应用且已回测的自定义条件时，自定义策略与固定定投并排对比；没有时仅显示固定定投结果。指标包含：累计投入、总资产、收益、年化 XIRR、投入收益率、净值最大回撤、买入次数，全部直接展示，不折叠。顶部标明按各自实际投入计算，不再突出「比固定定投多赚／少赚」或据此判断策略优劣。
6. 没有资金／回撤切换、定投明细、明细导出或「图表说明」入口。
7. 行情来源、内置数据标识与截至日期统一放在页面最底部，仅出现一次，图表顶部和结果标题旁不再显示。

## 默认规则

- 2026-09-21 已删除 ECDA 开关、默认涨跌加减投逻辑及相关说明。默认每期投入基础金额（1×）；仅主动应用的自定义条件可以修改本期倍数。
- 每次从基础金额计算，不将上次投入累乘；未命中条件时使用 1×，或用户明确设置的未命中倍数。
- 旧存档的 ecdaEnabled 字段直接忽略，保存后不再写回；保留标的、金额、频率、日期与已应用条件。不把旧 ECDA 自动转换成自定义规则。
- 已删除隐藏仓位、储备、冷却、旧最大／最小倍数、初始现金池及余额条件。每期直接投入并买入。

## 自然语言条件

- 复用 `LocalAIClient.researchAnswer(structured: true)` 和现有 AI 服务商配置；仅发送输入描述及已有规则，不附带账户或持仓。不会直接执行模型代码。
- `DCAConditionCompiler` 将返回值解析为受限规则：价格／SMA、RV、ER、区间高点回撤、区间涨跌幅、收盘价；最多 8 条规则、每条 8 个条件，只支持一层全部／任一满足。
- 窗口、阈值、方向和动作须明确。缺失参数列入 questions；不支持的跨资产、新闻、卖出、嵌套条件、冷却等列入 unsupported。有未解决项就禁止应用。格式失败最多自动修正一次；拒绝重复键、未知字段、无效单位范围和超过 3× 的动作。
- 原生编辑页使用本地草稿。支持启停、调整优先级、周期／方向选择、阈值编辑、倍数滑杆、移除／清空；「应用到回测」才更新并持久化正式配置。输入发生变化或关闭编辑页会取消旧请求，晚到回复无法覆盖草稿。
- 规则列表按固定 ID 读写，不保留数组下标绑定。删除和排序不会让原输入框写到相邻规则；清空／重新生成会使旧绑定失效，删除正在编辑的规则先解除焦点。删除最后一条后仍可直接应用清空结果。
- 从上往下使用首条满足的规则，倍数作用于基础金额，不累乘。未命中时默认固定 1×，也可指定固定倍数；判定历史不足时暂停投入和买入。只读取执行日前价格。固定定投对照组不使用自定义规则。
- 图例及对比列显示「自定义策略」与「固定定投」；没有自定义条件时只展示固定定投与其累计投入，不显示自定义策略曲线、图例或结果列。新增条件在运行后显示对比；清空／停用条件后立即隐藏旧自定义结果。界面上所选倍数直接决定目标买入额，不叠加隐藏的上下限或冷却。
- AI 接口已复用；自动化验证使用注入回复，不代表真实服务商语义正确率或连通性实测。

## 对比与资金口径

- 不再设置初始现金池，不预存或留存现金。默认基础金额 $500，可在金额面板修改。固定定投每期直接投入并买入 $500；策略为 1.5× 时投入并买入 $750，为 0.5× 时 $250，暂停时 $0。
- 两组使用相同频率、回测区间、行情，各自累计实际投入本金。旧存档中的 initialCash 被忽略，再次保存不再写回。
- 总资产 = 持仓市值；每组收益 = 市值 − 该组累计投入，投入收益率分母也是各自本金。投入收益率不考虑入金时间，XIRR 考虑每笔入金金额与日期。界面明确这不是同预算策略优劣结论；2026-09-20 已移除突出收益金额差的胜负式表述。
- 图表灰线为自定义策略累计投入；固定定投本金在对比表单独显示。两组最大回撤按各自剔除新增投入影响的单位净值计算。
- 两组仅持有同一资产，没有现金余额或卖出，在相同持有区间内单位净值收益路径和最大回撤相同；不能用该指标判断加减投入的效果。
- XIRR 复用 `MoneyWeightedReturnCalculator.rolling`，分别使用各自实际买入金额／日期求解，从各自首次非零投入算起年化；不足30天不年化，完全未投入不显示收益率。
- 非交易日顺延，月末按原日期锚定；指标只使用买入前的收盘数据。真实模式使用拆股复权收盘价，不补假价格；不计分红、手续费、税费。正常回测始终使用真实历史行情，不跟随模拟持仓模式；仅 Debug 显式传入 `--dca-demo` 可用合成行情进行界面测试，Release 不启用该参数。
- 配置保存在设备，不写组合账本、不下单。

- 单独请求 Yahoo chart API，并用 Python 独立构建每周购买记录、股份和本金对账：157 次购买；ECDA 本金 $69,250、市值 $89,532.04、收益 $20,282.04（29.29%）；固定定投本金 $78,500、市值 $101,972.79、收益 $23,472.79（29.90%）。以上金额、收益率和收益差 $−3,190.75 均与原生界面一致。

## 内置 SPY 历史

- `Resources/spy_daily_history.json` 随 iOS App 打包，包含 Yahoo Finance 的 8,467 条真实日线（1993-01-29 至 2026-09-18），378,680 字节，约 370 KiB。记录来源 URL、下载时间、价格口径、起止日期与条数，不生成或插值价格。
- 使用拆股复权收盘价，与联网回测口径一致，不计分红。完整历史供指标预热使用，界面原有最长 10 年回测区间不变。
- 首次选择 SPY 立即读取本地资源并计算，后台刷新网络行情；离线、超时或不完整响应均保留已有历史。只接受覆盖已有交易日期的有效完整序列，避免混接不同复权价格。用户已修改的待运行配置不会被后台刷新自动提交。
- 回测结果记录实际使用的数据来源。使用内置历史时显示「内置 SPY」及回测数据截至日期；其他标的仍使用各自行情，不回退到 SPY。
- 更新随包快照：在仓库根目录运行 `python3 scripts/update_ios_spy_history.py`，审核数据后重新构建 App。脚本仅收录已结束日期，验证数据后原子替换，下载失败不覆盖已有快照。
