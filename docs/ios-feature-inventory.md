# Catfolio iOS 功能全清单

核对日期：2026-09-09。范围：当前工作区的 iOS App，用于官网内容规划；不包含旧 Web/Desktop 的独有功能。按代码、实际页面入口和项目说明核对，非 App Store 上线状态或逐项联网验收报告。

## 1. 账户接入与管理

- Trading 212：只读 API 接入，支持正式/模拟环境与多账户汇总。
- Moomoo：OAuth 授权，在 iPhone 上读取授权账户、持仓和历史成交，无需 OpenD。
- Interactive Brokers：Flex Web Service 导入，无需 Gateway。
- CSV：从系统“文件”导入，在本机解析并创建账户。
- 选择全部账户或指定账户，选择范围用于持仓、收益及研究。
- 账户详情、昵称修改、删除账户、查看账户交易记录。
- 手工补充历史交易，记录日期、证券、方向、数量、价格等。
- 同步状态、更新时间与失败提示。

来源：`SettingsView.swift`、各券商 View/Client、`CSVImportView.swift`。

## 2. 组合首页与持仓

- 汇总持仓市值、成本、盈亏及收益率。
- 市值与净入金历史曲线，多时间范围切换。
- 长按后单指拖动查看某日，双指测量区间变化。
- Today 今日盈亏摘要与主要持仓贡献。
- 持仓列表：股票名称、代码、数量、价格、市值和盈亏。
- 今日/持有期口径切换；按市值、盈利、收益率、名称升降序排列。
- 持仓热力图；点击持仓进入个股详情。
- ETF 穿透视图切换。
- 下拉刷新、缓存显示及加载/错误状态。

来源：`PortfolioView.swift`、`HoldingsHeatmapView.swift`。

## 3. 今日盈亏归因

- 单独的今日盈亏详情页。
- 按行业汇总贡献，进入行业查看成分。
- 分列推动上涨和拖累下跌的持仓。
- 可识别的 ETF 成分按比例归入行业；无行业资料的证券保留未分类。
- 当前按持仓市值与最近报价的涨跌推算，未计入今日买卖的影响。

来源：`TodayDetailView.swift`、`SectorAttribution.swift`。

## 4. ETF 穿透与重叠暴露

- 将支持的 ETF 拆解为底层股票，提供成本/市值分析能力。
- 合并同一股票的直接持仓与 ETF 间接持仓。
- 展示直接、间接、总暴露及重叠持仓。
- 按总暴露、间接暴露、直接持仓、名称排序。
- 精确基金成分快照优先；部分代码使用指数代理。
- 覆盖受内置资源限制，不是全市场或完整历史时点穿透。

来源：`ETFLookThroughView.swift`、`PortfolioView.swift`、`LocalServices.swift`。

## 5. 收益与组合分析

- 组合与 SPY、QQQ、VTI、GLD 等可用基准比较。
- 现金流镜像、TWR 时间加权、MWR 资金加权三种口径。
- 时间范围切换、图例系列选择、单日读取、双指区间测量。
- 回撤水下曲线与最大回撤。
- P/E 与成长估值矩阵，气泡大小表示仓位权重；可进入持仓详情。
- 依赖历史行情、现金流和估值覆盖；缺数据不等于零收益。

来源：`ReturnsView.swift`、`ReturnsAnalyticsView.swift`、`LocalReturnsAnalytics.swift`。

## 6. 个股行情与持仓详情

- 个股历史价格、多时间范围、拖动查看价格。
- 买入/卖出点标记、成本参考线。
- 跨账户查看同一证券的持仓信息。
- 持仓成本、市值、盈亏、汇率影响等数值，并区分券商报告、重建、估算与缺失状态。
- 52 周价格区间。
- Volume Profile 成交量价格分布：POC、VAH、VAL，与成本/现价对照。
- 行情刷新、缓存和来源相关状态。

来源：`VolumeProfileView.swift`、`LocalServices.swift`。

## 7. 期权 OI 持仓墙

- 个股详情内按执行价展示 Call/Put 未平仓量分布。
- 7/30/90 天到期范围切换。
- Call/Put 峰值、并列峰值与 OI 集中区；现价/成本参考。
- 直接读取 Yahoo 期权链，无需行情 API Key；手动刷新并保留本地缓存。
- 只处理可核验的 REGULAR 合约，首版限美国上市美元股票/ETF。
- 缺到期日、缺 OI 或请求失败时不以部分新数据替换完整缓存；429 冷却。
- OI 数据日期未知时明确保留未知；不能将 OI 称为成交量或 Gamma，也不能宣称必然支撑/阻力。

来源：`OptionsOIView.swift`、iOS README。

## 8. 公司财务、盈利与市场预期

- 利润表、资产负债表、现金流三类财务报表。
- 年度/季度切换；SEC Company Facts 优先，适用时回退已配置的 FMP。
- 同期重述采用最新申报，财务数字保留原报表币种。
- 盈利历史：每股收益/收入切换，实际值与预期值比较，刷新及历史横向浏览。
- 当前个股详情仍接入分析师一致预期、评级分布与目标价区间；具体可见字段取决于数据来源和覆盖。
- 相关 Polymarket 事件、概率、截止时间及外部事件链接，仅展示和研究。
- 注意：引擎清单记录用户不再需要继续扩建评级功能；现存代码与后续产品取舍应区分。

来源：`CompanyFinancialsView.swift`、`EarningsHistoryView.swift`、`AnalystConsensusView.swift`、`VolumeProfileView.swift`。

## 9. 市场研究与今天值得关注

- 市场关键指标、持仓涨幅榜、持仓跌幅榜。
- 美国 11 个行业 ETF 的板块表现。
- 名称/代码搜索，手动刷新，显示数据日期。
- AI 分析当前所选账户，生成值得关注的持仓。
- 展示发生了什么、关注理由、正反证据、风险与后续观察点。
- 高关注筛选、最大结果数设置，保留上次分析，手动重新生成。
- 行情采用最近可用收盘；涨跌榜仅覆盖当前持仓，不能称作全市场实时榜单。

来源：`ResearchView.swift`、`AIView.swift`。

## 10. 选股器

- 自定义市值、年度营收、TTM 市盈率、营收同比、净利率、自由现金流、距 52 周低点七类条件。
- 条件上限/下限编辑、添加和移除，保存筛选规则。
- 自然语言生成筛选条件。
- 运行、停止、分批继续核验，每批 20 家。
- 查看匹配依据，AI 解释匹配原因和局限。
- 依赖数据商覆盖、权限和请求额度；不能宣称无限制全市场实时扫描。

来源：`StockScreenerView.swift`。

## 11. 行业情绪

- 半导体行业情绪分数与市场状态。
- VXSMH 波动率趋势、SMH 成交量及时间范围查看。
- 当前组合的半导体直接持仓占比。
- 从 JSON 导入行情快照，读取并缓存本机数据。
- 目前是半导体专项、依赖快照导入；不是所有行业自动实时情绪服务。持仓比例不含现金及 ETF 穿透。

来源：`IndustrySentimentView.swift`。

## 12. AI 助手与个股正反方分析

- 主页面可进入 AI 对话，结合所选账户组合上下文问答。
- Apple 本地模型、ChatGPT Codex 登录、DeepSeek API Key 三类接入。
- 自动模式按 Apple 本地 → 已连接 Codex → DeepSeek 选择可用服务。
- Apple 本地需设备支持、Apple Intelligence 开启且模型就绪；远程服务需要网络和相应授权。
- 本机聊天历史、删除消息、清空对话，Markdown 内容展示。
- AI 新请求遵循界面语言，旧聊天与旧研究不自动重译。
- 个股正反方分析：关键问题、多空论据、新闻/申报/目标价来源及引用。
- 分析任务可在离开个股页后继续；AI 页面可查看结果和历史分析。
- 真实账户与公开投资者模拟账户的对话上下文隔离。

来源：`AIView.swift`、`LocalServices.swift`、`SecurityDebateView.swift`、`SecurityDebateStore.swift`。

## 13. History、现金活动与费用

- 跨账户资产活动流水：买卖、分红、利息、入金、出金、转账等已导入事件。
- 按账户、活动类型、年份/统计范围过滤。
- 历史收益汇总和已实现盈亏；优先保留可用券商结果，缺失时尝试本地重建。
- 查看历史处置匹配；底层包含 FIFO、英国同日/30 天匹配与 Section 104 成本池。
- 基金持有费用：根据当前市值和已取得年费率估算运行成本，不是实际扣款流水。
- CSV 导出历史记录。
- 费用不可重复从净值收益中扣除；已有成本池代码不等于税务申报功能开放。

来源：`HistoryView.swift`、`RealisedProfitCalculator.swift`、`UKShareMatching.swift`、`UKSection104Pool.swift`、`FundFeeCatalog.swift`。

## 14. 佩洛西模式与演示账户

- 公开投资者选择，可多选人物；独立模拟账户。
- 使用公开披露、历史报价构造持仓、交易、每日估值及历史曲线。
- 复用持仓、Today、History、Performance、ETF、个股详情和 AI。
- 另有完全虚构的演示数据选项，用于体验和截图。
- 模拟账本、演示账本与个人账户相互隔离；失败可回退缓存。
- 公开披露存在时滞，不能称作人物实时持仓、真实账户收益或自动跟单。
- 不能确认的证券/期权与缺失报价保留诊断；当前模拟不包含未取得的分红、费用和现金资产。
- 离线公开披露包目前截至 2026-09-07；尚未配置披露自动更新或对外分发。

来源：`PublicInvestorView.swift`、`PublicInvestorCatalog.swift`、iOS README。

## 15. 偏好、存储与可靠性

- 简体中文、English、跟随系统；切换即时生效。
- 浅色、深色、跟随系统；触控反馈开关。
- 原始公司名/中文简称。
- 九种显示币种：USD、GBP、EUR、CNY、HKD、CAD、AUD、SGD、JPY。
- 服务商密钥配置、验证、移除，Codex 登录/登出及连接状态。
- 本地持仓账本、日快照和缓存，系统文件保护，凭据保存在本设备 Keychain。
- 交易与持仓对账，显示不一致项；不会自动修复账本。
- 备份后重置本机组合数据及恢复提示。
- iCloud 同步允许列表内的偏好：外观、币种、公司名、触感、排序、部分研究与选股规则等。
- 不同步个人账本、券商凭据、账户选择、模拟模式；语言偏好保留在本机。
- 原生 SwiftUI；iOS 18 起支持，iOS 26 使用 Liquid Glass，旧系统材质回退。

来源：`SettingsView.swift`、`DesignSystem.swift`、`Localization.swift`、`CloudPreferences.swift`、`LocalPortfolioStore.swift`。

## 尚未开放或不能作为现有能力宣传

- 拍照 AI 添加持仓：禁用占位入口。
- 税务计算：禁用占位入口；不可宣传自动报税或完整税务系统。
- App 内下单、自动交易/跟单：本次核对没有发现执行入口。
- 全市场实时行情、全市场 ETF 穿透、所有行业自动情绪：当前不具备这些覆盖保证。
- 完整历史目标价回测：Core 只有试采/研究，不能视为可用 App 功能。
- 个人账本全量 iCloud 同步：当前明确不做。
- 正式官网下载：当前官网仍为下载状态提示，未接正式 App Store/TestFlight 链接。

## 官网内容分组建议

第一层主卖点：多账户统一管理、今日盈亏归因、收益对比、ETF 穿透、AI 研究、本地优先。

第二层能力展示：个股行情与成交量、OI、财务与盈利、选股、历史流水、公开组合模拟、多语言多币种。

第三层说明：数据覆盖、AI 服务选择、模拟口径、隐私边界和下载状态。
