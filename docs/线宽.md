# 线宽

更新日期：2026-09-14。范围：Catfolio 原生 iOS 客户端。

本文记录当前代码的线宽基线及各图表的覆盖值，供后续修改时查阅。当前并没有把所有图表统一为同一种线宽；下表中的差异是现有实现，不是待执行的统一方案。

## 单位与区分

- SwiftUI、Canvas 和 UIKit 这里使用的数值均为逻辑点（pt），不是截图的物理像素。不要按截图缩放比例直接回填代码。
- 数据折线、参考线、网格、标记轮廓、玻璃边缘和条纹填充用途不同，分别记录。
- 玻璃参考线的厚度由视图的 `height` 控制；它不一定通过 `stroke(lineWidth:)` 绘制。
- 线宽不等于点击区域。触摸范围由控件布局、`contentShape` 或图表交互层决定。

## 共享折线组件

| 对象 | 当前值 | 位置／说明 |
|---|---:|---|
| 数据折线默认值 | 2.25 pt | `StandardLineChartSeries.lineWidth`，调用处可覆盖 |
| 水平网格 | 0.7 pt | `StandardLineChart.drawGrid`；虚线和透明度另行配置 |
| 加载占位折线 | 与对应真实曲线相同 | morph 模板直接继承系列线宽；独立 skeleton 由调用处传入 `lineWidths` |
| 参考线默认值 | 2 pt | `StandardLineChartReferenceLine.lineWidth`，作为玻璃线的高度 |
| 竖向选择指示线 | 2 pt | 交互指示层的视图宽度 |
| 数据标记轮廓默认值 | 1.5 pt | `StandardLineChartMarker.outlineWidth`；动画中可能随标记缩放 |
| 面积填充内细条纹 | 0.75 pt | 装饰纹理，不是数据曲线 |

数据折线绘制时使用各系列自身的 `lineWidth`，动画数据转换也会携带这个值。不能只改默认值，就认为所有页面都会随之改变。

实现：[StandardLineChart.swift](../CatfolioIOS/CatfolioIOS/StandardLineChart.swift)。折线动画另见 [ios-line-chart-motion.md](ios-line-chart-motion.md)。

## 期权墙与玻璃标注

| 对象 | 当前值 | 说明 |
|---|---:|---|
| 期权分布轴线 | 0.5 pt | 普通描边 |
| 气泡移位后的引导线 | 1 pt | 连接真实位置和移位气泡 |
| 水平玻璃参考线／选择线 | 5 pt | 玻璃视图的高度 |
| 旧系统玻璃线替代样式边缘 | 0.5 pt | fallback 的胶囊轮廓 |
| 旧系统气泡替代样式边缘 | 0.5 pt | fallback 的胶囊轮廓 |
| 柱内宽斜条纹 | 11 pt | 填充纹理，不是轴线或数据线 |

为避免 PUT／CALL 气泡重叠时出现错误细线，当前处理规则是：

1. 参考线、选择线和引导线按所有气泡的实际边界裁切，而不只是本侧气泡。
2. 避让范围在气泡边界外增加 `4 + lineWidth / 2` pt。
3. 裁切后不足 8 pt 的短线段不绘制。
4. 移位气泡的引导线按实际气泡中心连接，不使用固定列中心代替。
5. 玻璃线位于气泡下层；不通过新增描边遮盖重叠瑕疵。

实现：[OptionsOIView.swift](../CatfolioIOS/CatfolioIOS/OptionsOIView.swift)，重点为 `OIPlotGeometry.uncoveredLineIntervals`、`markerRules` 和 `glassRule`。

## 明暗模式与修改边界

上面列出的主要折线宽度在明暗模式中相同；颜色、透明度、玻璃材质和末端点颜色可分别适配。不能把材质高光或截图抗锯齿产生的边缘误当作额外的数据线。

修改某一类线宽时，需要同时确认共享默认值和调用处覆盖值。修改期权墙玻璃线厚度时，绘制高度与避让计算的 `lineWidth` 应同步。图表线宽的调整不涉及金融计算。

## 加载时的线宽与形状

加载曲线不再统一使用 1.2 pt：资产和股价为 2.5 pt，收益对比和回撤为 2 pt，研究关键指标为 3 pt；多系列图按各自实际线宽传入。首次 morph 的占位系列同时继承真实系列的虚线设置和末端点大小。

闪光是一条沿占位形状移动的柔和亮度波，严格以形状自身作为遮罩，不增加描边、外发光或粗细变化。 加载折线参考 Figma `236:38675` 的平顺折角和末端空心圆，几何按当前页面尺寸自适应；不照搬参考中的数据或排版。线条与圆环先合成一份轮廓，再扣除圆心，最后统一着色，避免半透明重叠加深或露出线头。真实曲线和首次过渡也在端点圆环范围内裁切线条。文字、数值、图标以相近宽高的圆角矩形或圆形代替；柱形图、期权墙、轮动图采用对应类型的形状占位。

这次修改不改变金融计算。按用户要求不运行测试，实际视觉效果由用户验证。
